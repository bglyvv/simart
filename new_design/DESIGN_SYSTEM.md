3. Typography
Font: Inter.

Recommended hierarchy:

Display: 40–48px
H1: 32px
H2: 24px
H3: 20px
Body: 15–16px
Caption: 12–13px
Use medium and semibold weights for headings.

Avoid excessive bold typography.

5. Components
Buttons
Primary: black background, white text.
Secondary: white background, neutral border.
Tertiary: text-only.
Minimum touch target: 44px.
Cards
White background.
1px neutral border.
16px radius.
Subtle shadow only when necessary.
Consistent internal padding.
Inputs
White background.
Neutral border.
10px radius.
Clear focus state.
Visible labels.
Helpful validation messages.
Navigation
Desktop:

Fixed or sticky sidebar.
Active item uses subtle neutral background.
Simple Lucide icons.
Mobile:

Five-item bottom navigation.
Clear active state.
Appropriate safe-area spacing.
6. Charts
Use restrained charts:

Neutral bars.
Sage highlights.
Minimal grid lines.
Clear legends.
Readable labels.
Avoid unnecessary chart decoration.

7. Accessibility
Maintain sufficient color contrast.
Never use color as the only status indicator.
Provide keyboard navigation.
Use semantic form labels.
Support reduced motion.
Make mobile controls easy to operate.
8. Motion
Use subtle transitions:

150–250ms for hover and focus.
Gentle opacity and transform transitions.
Avoid distracting animation.
Respect prefers-reduced-motion.
9. Responsive breakpoints
Suggested:

Mobile: below 640px
Tablet: 640–1023px
Desktop: 1024px and above
The actual implementation should follow the existing framework conventions.
